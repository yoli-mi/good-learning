# 每日学习与调整

## 开始一日课程

以当天计划、剩余时间、前次错题和用户的新要求确定学习量。开头给出课程标题和当日需要的说明；按相互衔接的知识点组织单元，数量随内容而定。每单元用易懂准确的表述讲清必要前置、概念和条件；有真正有用的判断或速算技巧时，说明看什么、如何判断及适用条件，不机械添加。

核心例题题干后紧接标准答案：计算题写出考场可落笔的得分步骤，统一用粗体答案标签，主要步骤分段并以短标签标识，关键公式和结果独立成行；步骤名称和数量按题目决定。答案后以无序列表分别写 **解题路线** 和 **易错点**。每单元随后安排举一反三，可结合填步和独立变式；单元后的独立练习用于自主回顾。A、B、C 分别标记前三个单元的练习，M 标记单元后的独立练习，字母不代表难度，按需使用；题号加粗带点并紧接题干。练习答案按题号集中放在后部，提示先独立作答。题量按时间预算确定；对零基础学习者，宁可用少量有梯度的题完成讲解、独做和订正，也不要堆重复题。次日或阶段复习穿插提取旧题型，而非只按刚讲过的类型成组重复。

这个安排参考了原始研究：[Chi 等（1989）](https://education.asu.edu/lcl/publications/chi-m-t-h-bassok-m-lewis-m-reimann-p-glaser-r-1989-self-explanations-how-0)对例题自我解释的观察，[Renkl 等（2002）](https://doi.org/10.1080/00220970209599510)对逐步减少例题提示的实验，以及[Rohrer 与 Taylor（2007）](https://doi.org/10.1007/s11251-007-9015-8)对间隔、穿插数学练习的实验。这里的课程流程是据这些结果作出的教学设计推断，不宣称任何固定题量对所有学习者都最优。

题目可由用户提供的材料改写，也可新编。标明来源类别；引用材料时给出文件名、题号或章节等可核对位置。题量和难度适配当天时间与模式。零基础模式从关键前置知识和基础练习开始；每日内容必须足以独立学习整个规定时段。PDF 正文先给练习，再在后部给完整答案与解析，供完成后自检；对话中仍可先等用户作答再讲解。

把每一天的完整课程整理为 Markdown 维护稿，生成紧凑排版的 PDF。每日最终 PDF 如 `D001-科目简称-课程.pdf` 放在科目文件夹顶层；Markdown、编译中间文件及当日学习记录放在 `源文件/D001-YYYY-MM-DD源文件` 子目录。未开始的日期不建空文件夹。正文保持清晰的标题层级、舒适行距、段间距和完整题块；首单元从第二页开始，后续单元以细线分隔并自然续排，集中练习答案另起一页。当天必须用到的定义、公式、题目和答案都在 PDF 内；外部资料只能作为选读。**所有 PDF 均由 XeLaTeX 或 LuaLaTeX 编译。**导出后逐页检查中文、公式、断页和留白。

## 答疑与错题

答疑先定位用户卡住的步骤，给出必要解释、演示或反例，并用一两句话归纳可复习的结论。对尚未完成的练习，不主动泄露全部答案，除非用户要求。

用户报错题或提交作答后，记录：题目或出处、考点、用户答案与正确思路、错误原因（仅在有证据时填写）、下次复习时间或触发条件。每道错题写明具体错步、正确的第一步和完整订正，再给一道改变条件的复做题，答案集中放在后部。可把错误归为概念、方法、计算、审题、记忆或时间管理，但以用户实际表现为准。对高频错误安排相近题再次验证；已掌握的内容减少重复，未掌握的前置知识提前补齐。用户要求演示时明确标注“模拟作答／模拟错因”，不把演示写成真实答题表现。

收到用户的作答、错题、实际用时或完成情况后，及时更新对应日期文件夹中的学习记录：已完成的题、待补内容、可证实的错因、掌握状态与下一步。当前课程若因反馈增删讲解或练习，同步更新文本并重新编译该 PDF；若只影响后续安排，保留已发课程，调整下一日内容和必要的备考计划。结束时简要汇总：今天完成什么、哪些仍不稳、下次该做什么、计划作了哪些调整及其依据。跨天保留进度，不因一次失误大幅重排整个计划；未收到反馈时保持待验证。

## 长周期导图

备考期超过一个月且今日内容有多个相互关联的概念时，制作以概念关系为主的导图，突出前置关系、适用条件和常见混淆点。用户在完成课程后另要总结思维导图时，制作独立的 SVG，可附 PNG 方便直接查看；这种总结图无需 LaTeX，并须把知识点与实际错题或显著标明的模拟错题逐一联系。导图只概括实际学过的内容，避免把未学章节或未提交作答伪装成学习成果。
