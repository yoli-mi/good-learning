# 错题重做纸

单道错题的**对照图**：左边是学习者自己的解题过程（从出错那一步起整段标红），右边是订正后的正解；页面顶部先给错误诊断，右栏顶部给易错点与考察重点。输出 PNG，适合手机查看、群聊讲解和打印。

和错题本 PDF 的分工：

| | 错题本 PDF（`render_study_pdf.py --kind errors`） | 错题重做纸 PNG（本脚本） |
|---|---|---|
| 内容 | 多条错题归档、可打印 | 单道错题的前后对照 |
| 重点 | 记录完整、可复做 | 一眼看出"我在哪一步错了、正确的长什么样" |
| 版式 | 逐题分页的文档 | 左右两栏、错步标红 |
| 公式 | LaTeX 排版 | 轻量排版（分数叠放、真上下标），不依赖 LaTeX |

## 什么时候用

- 用户提交作答、核对完发现某一步错了，需要**把事情说清楚**时
- 需要在群里/手机上直接看图，而不是打开 PDF 时
- 家长或老师要看"错在哪、怎么改"时

归档仍然用错题本 PDF；两者可以同时产出。演示用的错误要在 `diagnosis` 里注明"模拟"，不要混进真实掌握状态。

## 输入

```json
{
  "title": "第 2 题 · 隐函数求导",
  "diagnosis": "错因：概念混淆 + 符号错误。……",
  "my_steps": ["由 e^y + xy = e", "……", "结果：y''(0) = 2/e²"],
  "error_from": 8,
  "correct_steps": ["e^y + xy = e，x=0 → y(0) = 1", "……", "y''(0) = 1/e²"],
  "pitfalls": ["e^y·y' 再求导是两项……", "(y')² 的系数是 e^y……"],
  "knowledge_point": "隐函数求导与二阶导数"
}
```

| 字段 | 说明 |
|---|---|
| `title` | 纸头标题，例如「第 2 题 · 隐函数求导」 |
| `diagnosis` | 错误诊断：错因归类 + 一句话点破根因。可多行，用 `\n` 分隔。散文段落不做分数排版 |
| `my_steps` | 学习者自己的过程，**原样转录，不要帮着改对**。一行一步，空行分段，行首两个空格表示缩进 |
| `error_from` | 从第几行开始算错（从 0 数）。该行及之后全部标红；`-1` 表示不标红 |
| `correct_steps` | 订正后的正解，一行一步 |
| `pitfalls` | 易错点 / 考察重点，一行一条 |
| `knowledge_point` | 本题考点，一句话，可选 |

## 版式规则

- **两栏**：左栏自顶部向下排「错误诊断 → 我的过程」；右栏自顶部向下排「易错点 / 考察重点 → 本题考点 → 正解」。没有通栏块。
- **标红**：`error_from` 及之后的行用红色；前面正确的部分保持墨色，让"从哪一步开始错"一眼可见。
- **一页放不下**：自动拆成两页——第 1 页「错误记录」（诊断 + 我的过程，跨两栏续排），第 2 页「正解」（易错点/考察重点在最前，随后正解）。
- **行距**：正文落在 38px 的基线网格上；含分数的行占两格并垂直居中，所以整页节奏一致，不会一行高一行矮。
- **分数**：分数线不压在文字基线上，而是抬到"数学轴"（约 0.3 字高）上，和同一行的数字、等号、运算符视觉对齐。
- **背景**：5mm 方格纸（150 dpi 下 38px），格线与正文行距同值，字落在格子上。

## 公式写法

脚本自己排版，不需要 LaTeX：

| 写法 | 渲染 |
|---|---|
| `\frac{a}{b}`、`a/b`、`(x+1)/(2y)` | 上下叠放的真分数（可嵌套） |
| `x^2`、`e^{A}`、`a_{n+1}`、`x²` | 真上标 / 下标 |
| `\sqrt{x}` | √x |
| `\to \infty \pi \cdot \approx \neq \leq \geq \times \Delta` | → ∞ π · ≈ ≠ ≤ ≥ × Δ |

自动识别 `a/b` 只在**看起来是公式**的行上生效：含 `=`、`→`、`^`、`lim`、`ln` 等记号；带 URL、斜杠紧贴中文（"上午/下午"）、或中文超过 6 个字（叙述句）的行保持原样。`^` 与 `_` 后面的指数、下标组里不插分数——那里画不了叠放，插进去只会把 `\frac` 漏成文字。

## 运行

```text
python scripts/render_mistake_sheet.py examples/mistake-sheet.json sheet.png
python scripts/render_mistake_sheet.py in.json sheet.png --dpi 300 --font /path/to/font.ttc
```

- 依赖 Pillow（`pip install -r requirements.txt`）；中文字体可用 `--font` / `--bold-font` 指定，或通过 `GOOD_LEARNING_FONT` 环境变量；脚本会先找常见字体
- 多页时第一页写到 `sheet.png`，其余为 `sheet-2.png`、`sheet-3.png`
- 加 `--pdf sheet.pdf` 会额外产出一份 A4 PDF（多页时合成一个文件），用于单独交付或并入其他 PDF

## 放进错题本 PDF

这张图既能单独发，也能直接印进错题本 PDF：

1. 生成图片，文件名用 ASCII、和错题本的 `.tex` 放在同一个 `源文件` 目录：

   ```text
   python scripts/render_mistake_sheet.py 第2题.json 科目/源文件/sheet-error-2.png
   ```

2. 在错题本 Markdown 的该错题小节里**单独一行**引用它（放在订正之后、“再做一题”之前）：

   ```markdown
   ### 订正

   ……订正正文……

   ![错题重做纸：第 2 题](sheet-error-2.png)

   ### 再做一题
   ```

3. 照常渲染并编译：

   ```text
   python scripts/render_study_pdf.py 科目/源文件/错题本.md 科目/源文件/错题本.tex --kind errors
   python scripts/compile_study_pdf.py 科目/源文件/错题本.tex 科目/错题本.pdf
   ```

`render_study_pdf.py` 会把这一行转成通栏插图（宽度撑满正文、高度上限 0.86 页，带图注），`compile_study_pdf.py` 会把被引用的图片一并复制进临时编译目录——中文**目录**没问题，中文**文件名**不行；缺图或非 ASCII 文件名会在编译前给出明确报错。

## 实现

脚本只有 Pillow 一个依赖，排版是自己算的：

**1. 记号 → 节点树。** `parse_nodes()` 把一行拆成三类节点：`Txt`（普通文字或 `sup`/`sub` 上下标）、`Frac`（分子 + 分母两个子节点列表）。`\frac{a}{b}` 递归解析，所以可以嵌套。`prettify()` 在解析前做两件事：把 Unicode 上下标（`²`、`ₙ`）还原成 `^{2}`、`_{n}`；把 `a/b` 这类斜杠写法补成 `\frac`——只在"看起来是公式"的行上做，带 URL、斜杠紧贴中文、或中文超过 6 个字的叙述句一律跳过。

**2. 量尺寸。** `measure()` 返回 `(宽, 基线上高度, 基线下深度)`。分数按照排版惯例算：`up = 分子高 + 分子深 + 间隙 + 数学轴`，`down = 分母高 + 分母深 + 间隙 − 数学轴`——这样分数线落在数学轴（`MATH_AXIS = 7`，约 0.3 字高）上，和同一行的等号、数字齐平。

**3. 排版到网格。** `line_units()` 用 `ceil((上高 + 下深) / ROW_H)` 决定这一行占几个 38px 行带：普通文字 1 格，含分数 2 格。行带内垂直居中，所以整页节奏一致，不会一行高一行矮。

**4. 折行。** `wrap_nodes()` 优先在空格断行；单个长文本串逐字切，`base_w` 记录本行已占宽度避免切超；上下标不会单独落到行首——放不下时把底数和它一起挪到下一行。

**5. 一页还是两页。** 先在空白页上把左右两栏各排一遍（`draw=False`），任一侧返回溢出就改出两页版：第 1 页诊断 + 我的过程（跨两栏续排），第 2 页易错点 + 正解。

**6. 输出。** `--dpi` 会等比缩放全部版式常量（用 `apply_dpi()` 重算模块级常量），所以 150 和 300 dpi 的版式完全一致；`--pdf` 用 Pillow 直接把页面存成 A4 PDF（多页合成一个文件）。

嵌入 PDF 那部分只有两处改动：`render_study_pdf.py` 里 `image_tex()` 生成 `\includegraphics` 插图（TeX 里只写文件基名，中文目录不会进到编译器）；`compile_study_pdf.py` 里 `collect_images()` 在编译前收集被引用的图片并复制进临时构建目录。

## 交付前检查

- 红色起始行对不对：`error_from` 数的是 `my_steps` 里的行号（空行也算一行）
- 正解是否覆盖了错解里出错的那一步，而不只是给个结果
- `pitfalls` 是否点到了考点，而不是重复题目
- 渲染完成后看一眼图：分数是否叠放、有没有一行被挤到栏外
